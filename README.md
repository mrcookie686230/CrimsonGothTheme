# How to Install Vencord & Discord Themes

Follow these simple steps to install Vencord and add custom themes to Discord.

## Part 1 — Install Vencord

### Step 1 — Download Vencord

Go to the official Vencord website:

[Download Vencord Installer](https://vencord.dev/download/?utm_source=chatgpt.com)

Download the installer for your operating system.

### Step 2 — Close Discord

Completely close Discord before starting the installation.

### Step 3 — Open the Installer

Run the Vencord Installer.

The installer should automatically detect your Discord installation.

### Step 4 — Select Discord

Select the Discord installation you want to modify and click **Install**.

> **Important:** Do not run the Vencord installer as Administrator.

### Step 5 — Restart Discord

Wait for the installation to finish, then completely close and reopen Discord.

### Step 6 — Check Vencord

Open:

**Discord → User Settings**

You should now see a **Vencord** section.

If you can see it, Vencord is installed successfully!

---

# Part 2 — Install a Custom Theme

### Step 1 — Open Vencord Themes

Go to:

**User Settings → Vencord → Themes**

### Step 2 — Download a Theme

Download the `.css` file of the theme you want to use.

For example:

`KukkiTheme.css`

Make sure the file ends with **`.css`**.

### Step 3 — Open the Themes Folder

Inside:

**User Settings → Vencord → Themes**

click **Open Themes Folder**.

### Step 4 — Add the Theme

Move or copy your `.css` file into the themes folder.

Example:

`CrimsonGothic.theme.css`

### Step 5 — Enable the Theme

Go back to:

**User Settings → Vencord → Themes**

Find your theme and switch it **ON**.

### Step 6 — Enjoy!

Your custom Discord theme should now be active.

If it doesn't appear immediately, try **Reload Themes** or restart Discord.

🎉 **You're done! Vencord and your custom theme are now installed!**
