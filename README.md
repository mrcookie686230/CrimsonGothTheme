# CrimsonGothTheme
If you want to add the theme to Vencord
1. Open Discord.
2. Go to User `Settings ⚙️`.
3. Scroll down to `Vencord` → `Themes.`
4. Under `Online Themes`, paste the Raw GitHub URL of the `.theme.css` file.
5. Press Enter / click outside the box.
6. Turn the theme ON.
7. Restart Discord if the theme doesn't appear immediately.
Then your Theme is set On
